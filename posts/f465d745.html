DSH辅助站点升级整修记录

发表于 2026-11-16|更新于2026-11-17|经验修改DSH
|字数总计:1829|阅读时长:6分钟|阅读量:—

访客计数由于更换从 Hexo 6.3 换到 8.1被重置。

这次集中整修按批次推进，前后一共 49 项改动，下面按主题归档，方便以后回看每一处改动的动机。

一、迁移与旧站回归

  • 以 hexo-8.1.0 定为正式站，hexo-6.3.0 只作只读基线；主题层改动集中在 source/ 与 _config.fomalhaut.yml，不动 node_modules/hexo。
  • 主题色恢复旧站的 rgb(102, 204, 255)（cursor.js 与 settings.js 三处默认值一起改）。
  • 页脚「猜你想看」恢复旧版 5 行 10 条；7 枚徽章（Hexo / Butterfly / Fomalhaut / 萌ICP备 20247512 / Vercel / GitHub / Cloudflare）全部回位。
  • 四处注入层恢复：translate.js、左下固定 APlayer（歌单 5070943926）、右下 sakana-widget@2.7.1、Umami 统计。
  • 评论区接回 Twikoo（speak.qwqsky.top），并补出 /comments/ 留言板。
  • 关于页、旧时光、朋友圈、八音盒、网址导航、留言板等旧站内容逐页搬回，外观仍用新版。
  • 首页与文章页的旧配置从 fomal.js / qwq.js 迁到新模块，旧站里的修 bug 补丁不搬。
  • 全站构建 + 链接总核查：所有 *.qwqsky.top 链接逐条对照目标页面存在。

二、界面与导航的细节修正

  • 侧栏去掉「最新文章」卡；公告栏换成 anno2 / a-chip 结构，内容仍是主域名、备用域名和 APP。
  • 「猜你想看」补回「我的画廊」入口。
  • 删除独立的游戏页；favicon.ico 换回旧站文件（16295 B）。
  • 欢迎信息改成「点按钮才请求定位」，不再进页面就自动发起定位请求。
  • 繁中切换接回 qwq.js 并精简（367 → 358 行：去掉调试 log 与未用变量）。
  • 左下固定播放器补 data-api，歌单接口实测可用。
  • 首页头像后的背景图换成 102097784_p0_tra.png（日）/ 123214319_p0_tra.png（夜）。
  • 画廊改成 img.qwqsky.top/img/ 的 23 张图，瀑布流展示。
  • 友链流水线搬回：link.js 读 _data/link.yml 生成 source/friend.json，并加 npm run friend / friend:build。

三、朋友圈、统计与背景

  • 朋友圈换回旧站 fclite 前端（取数是 ${private_api_url}all.json），不再用 moments5；private_api_url 指向 https://fc.qwqsky.top/。
  • 新增 source/css/fcircle.css 做浅色/深色适配，挂到 inject.head。
  • 背景图配对修正：亮色 92817067、暗色 92968709，defineBg 与 resetBg_ 保持一致。
  • 画廊从分页改为单页：23 张整图，前端随机挑 20 张渲染，去掉 p2.html。
  • 统计页的 Umami 分享页带 X-Frame-Options: SAMEORIGIN，iframe 必被拦。改为前端请求 Umami 的分享接口，直接渲染访客、浏览量、访问次数、平均停留四项。
  • 重写 source/js/census.js 为 Umami 加载器，同步清理 census.css 里的百度图表/iframe 样式，删掉 baidu_analytics 配置。
  • 百度统计与 51LA 的脚本、注入、统计页残留全部清除，页面只保留 Umami 与 GitHub 贡献日历。
  • GitHub 贡献日历：脚本和样式已自托管，并打了「取数失败就收起转圈」的补丁。数据源接在 hpQc/gitcalendar-data：GitHub Action 每天 04:23 生成 gitcalendar.json，_config.yml 的 jsonurl 指向该仓库 main 分支的 raw 地址，前端直接 fetch，不用重新构建站点；本地构建时另抓一份同源快照兜底。

四、播放器：从覆盖样式到回退

  • qwq.js 里针对 APlayer 的 CSS 全部限定到 .aplayer-fixed，八音盒里的内嵌播放器恢复主题原样（16px 圆角、主题色高亮）。
  • 移除 inject.head 的 /css/aplayer-fixed.css，左下播放器回到旧教程的收起态（只露左侧把手）。
  • 固定播放器上移，bottom: 56px !important，展开时不再盖住左下角的 FPS 检测器。
  • 不再使用的 aplayer-fixed.css、51la.js 归档到 D:\AITool\_archive\20261116-aplayer-51la-cleanup。

五、页脚徽章与繁简/翻译

  • 徽章左侧的 Demo 改为 哈基米（两个状态图案各 4 处）。
  • 7 枚徽章恢复旧版图案并改用本地 /assets/badge/ 资源，避免外链图片失效。
  • 徽章加一道鼠标/触摸持续触发的浅色光扫，动画时长 1.55s。
  • 主题自带 #translateLink 只显示「繁」，而 translate.js 并不会自动绑定。改为手动接管点击，在 chinese_simplified ↔ chinese_traditional 间切换，按钮文案同步「繁 / 简」。
  • 按旧教程补翻译语言按钮，可切 English、简体中文、繁體中文、한국어、日本語。
  • 去掉浏览器翻译提示：qwq.js 里那段 translate-notification 通知（含 localStorage 的 translatePromptAcknowledged 标记，以及 DOMContentLoaded、pjax:complete 两处调用）整段删除，中文页面不再向非中文浏览器弹英文提示。
  • 语言选择框按固定像素重做：.translateSelectLanguage 从 width: 10%、padding: 10px 15px、font-size: 16px 改成 132 × 40 px（box-sizing: border-box、圆角 8px、14px 字号、右侧 12×8 的 SVG 箭头），隐藏位从 right: -300px 收到 -200px（框宽 132px，留够余量）；过渡由 all .3s 收到只动 right / border-color / box-shadow，百分比宽度不再随视口反复触发布局重算。

六、BB 空间、运行时间与旧时光

  • BB 空间原来的大图封面卡换成两枚紧凑入口卡（BB动态 / 梦中阁）。
  • 页脚「本站运行了」起算时间从误写的 2022-08-09 改为 2024-02-01，控制台字符画里的天数和版权年份一并修正。
  • 旧时光时间轴按批次追加摘要，作为站史入口。

七、2026-11-17：一批基础库集体失效

这是本次最费解的一次：页面骨架和背景都在，但图片几乎全是空白，点击放大、复制链接、分享、播放器、评论、公式、搜索全部失灵。

  • 现象与定位：控制台与网络里出现大量 net::ERR_BLOCKED_BY_ORB，命中的是 registry.npmmirror.com 上的 jQuery、clipboard、lazyload、fancybox、FontAwesome、APlayer、sakana、mathjax、twikoo。
  • 根因：该 CDN 对浏览器的子资源请求返回 403（防盗链）。命令行请求是 200、Content-Type 也正确，所以从 HTTP 状态看一切正常——这是判断被带偏的地方。浏览器拿到 403 后被 Chrome 的 ORB 判成不可信脚本丢弃。
  • 放大原因一：页面里的图片都是 <img src=1px占位 data-lazy-src=真地址>，负责换地址的 vanilla-lazyload 正好在被拦名单里，于是全站图片不显示。
  • 放大原因二：Fancybox 缺失时 main.js 的 runLightbox() 抛出 Fancybox is not defined，异常把同一个 DOMContentLoaded 回调里后面的 unRefreshFn()（含懒加载初始化）整段中断。两处必须一起修。
  • 处理：把 11 个库改为自托管，落在 source/js/lib/、source/css/lib/（含 FontAwesome 的 woff2/ttf 字体），_config.fomalhaut.yml 里 15 处 CDN 地址改成根路径。
  • 两个细节：FontAwesome 的 CSS 要单独放一层 /css/lib/fontawesome/，../webfonts 才能落到 /css/lib/webfonts；gulpfile.js 的 minify-css 用 clean-css 的 ie11 兼容模式，会把 FontAwesome 的 @font-face 压坏，所以把 public/css/lib/**、public/js/lib/** 从压缩范围排除。
  • 验证：滚动后图片正常换真图；FontAwesome 的 font-family 解析为 Font Awesome 6 Free；自家资源无 404。

验证

  • 构建：hexo generate 通过，无 ERROR/WARN；生产链路 hexo generate + gulp 后产物同步。
  • 交互：图片懒加载、站内搜索、FontAwesome 图标、sakana 挂件、右下角繁简与翻译按钮逐项点检。
  • 记录：本次排查的完整过程（含误判与验证数据）另存为 D:\AIWork\BlogBuild\排查记录-CDN资源不加载-20261117.md，文章里只留结论级摘要，方便回看出处。
